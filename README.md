# Проект Telegram_Async_VPN

## Краткое описание:
Телеграм бот, разделённый на 3 независимых друг от друга сервиса, общающихся исключительно через RabbitMQ. Бот принимает запрос пользователя и передаёт его в worker, который, в свою очередь, обращается к стороннему [API](https://github.com/kyoresuas/amnezia-api) для создания ключа конфигурации VPN, после чего он передаётся пользователю.

## Установка и запуск через docker-compose:
1. Скопируйте готовый или создайте свой docker-compose.yml.
2. Создайте .env с параметрами, приведёнными ниже.
3. Все образы будут взяты с соответствующего Docker Hub, а потому не забудьте обновлять их по мере необходимости.

## Переменные окружения:
| Переменная | Описание | Пример значения |
| :--- | :--- | :--- |
| **`BOT_TOKEN`** | Токен Telegram-бота | `712345678:AAH...` |
| **`FASTIFY_API_KEY`** | Ключ из env [amnezia-api](https://github.com/kyoresuas/amnezia-api) | `9a3eef...` |
| **`API_URL`** | URL для запросов к API | `http://127.0.0.1:4001` |
| **`RABBITMQ_PASSWORD`** | Пароль для базы RabbitMQ | `my_password` |
| **`RABBITMQ_URL`** | URL для обращений к RabbitMQ | `amqp://vpn_app:password@rabbit_node:5672/` |

**ПРИМЕЧАНИЕ:** рекомендую объединить контейнеры amnezia-api, а также контейнеры vpn_bot в одну общую сеть на вашем сервере, чтобы запросы поступали корректно.
